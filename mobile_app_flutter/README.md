# Flutter App Starter

This Flutter app provides manual scan actions for:
- URL phishing detection
- Image-name AI-generation detection

## Run

1. Ensure Flutter SDK is installed and in PATH.
2. Run:
   - `flutter pub get`
   - `flutter run`

## Backend URL

Default backend URL is in `lib/config.dart`:
- Android emulator: `http://10.0.2.2:5000`
- iOS simulator can use: `http://127.0.0.1:5000`

Update this constant based on your device or LAN IP.
